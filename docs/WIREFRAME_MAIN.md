## 🧩 2. 영역별 상세 UI 컴포넌트 명세

### ① TopBar (상단 네비게이션)
* **높이**: 56px, `sticky top-0`, `z-index: 30`
* **좌측**: 원형 이니셜 로고 badge(28px, Toss Blue) + 프로필명 타이틀("박다정 프로필", 17px 볼드)
* **우측**: 원형 공유 버튼(36px, `bg-grey-100`, 클릭 시 현재 URL 클립보드 복사 및 토스트 피드백)

### ② 프로필 헤더 카드 (Profile Card)
* **컨테이너**: `bg-white`, `rounded-2xl`(20px), `border: 1px solid #F2F4F6`
* **상단 행**:
  * 좌측: 64px 원형 아바타 (연한 파란색 배경 `#EBF3FE` + 파란색 텍스트 "다정")
  * 우측: 상태 캡슐 뱃지 (`#EBF3FE` 배경 + 파란 도트 + "커피챗 환영", 12px)
* **중단 정보**:
  * 이름: 24px 볼드 (`#191F28`)
  * 직무: 15px 미디엄 (`#4E5968`)
  * 한 줄 소개: 14px 레귤러 (`#6B7684`), 행간 1.5
* **하단 태그 행**: 구분선 상단 마진 후 기술 스택 태그 칩들 (`bg-grey-100`, 텍스트 12px)

### ③ 카테고리 필터 칩 (Filter Chips)
* **스타일**: 높이 36px, `rounded-full`(999px), 가로 스크롤 대응
* **활성(Active)**: `bg-[#191F28]` (짙은 네이비블랙) + 텍스트 화이트
* **비활성(Resting)**: `bg-[#F2F4F6]` (연회색) + 텍스트 `#4E5968`

### ④ 리스트 로우 (TDS List-Rows Container)
* **컨테이너**: `bg-white`, `rounded-2xl`(20px), 카드 내부 아이템 간 `border-b: 1px solid #F2F4F6`
* **아이템 단위 구성**:
  * **좌측 아이콘**: 44px 둥근 사각형(`rounded-xl`), `#F2F4F6` 배경 + 20px 브랜드 라인 아이콘
  * **중앙 텍스트**:
    * 1열: 링크 타이틀(15px 볼드) + 선택적 강조 뱃지(11px, 예: "업데이트", "v2.0")
    * 2열: 부가 설명(13px, `#8B95A1`, 말줄임 지원)
  * **우측 액션**: Chevron Right 화살표 (`#B0B8C1`)

### ⑤ 인터랙션 피드백 (Toast & Modal)
* **토스트 (Toast)**:
  * 화면 상단 중앙 64px 위치에 등장
  * 다크 배경 (`#333D4B`), 화이트 텍스트, 체크 아이콘, 2.4초 후 자동 페이드아웃
  * 트리거: 공유 버튼 클릭("프로필 링크가 복사되었어요"), 이메일 항목 클릭("이메일 주소가 클립보드에 복사되었어요")

### ⑥ 하단 고정 Primary CTA (Floating Action Button)
* **위치**: `fixed bottom-0`, 화면 중앙 정렬 (`max-w-lg`)
* **보호 레이어**: 상단으로 투명하게 빠지는 화이트 그라디언트 (`linear-gradient(to top, #ffffff, transparent)`)
* **버튼 스펙**: 높이 56px, `bg-[#3182F6]`, 텍스트 17px 세미볼드, 화이트, `rounded-2xl`
* **동작**: 클릭 시 기본 메일 클라이언트 열기 (`mailto:p29522295@gmail.com`)
